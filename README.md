## 🚀 Agentic Upgrade (New!)
Your JARVIS can now understand intents for **Gmail** and **WhatsApp**. 

### Commands you can try:
- "Jarvis, check my latest emails."
- "Jarvis, send a WhatsApp to Dad saying I'm almost done with the project."
- "Jarvis, read my unread WhatsApp messages."

## 🛠️ Setup
1. Connect WhatsApp account integration: [Connection Link](https://app.emergent.sh/wing/integrations/whatsapp/connect?wm=dee58d7c-0e71-41eb-8504-da3cf215ea84)
2. Ensure Gmail is connected.
3. Run `git pull origin main` on your Pi.
4. Launch `python3 jarvis_os.py`.

## 📂 System Components
- **jarvis_os.py**: Full-screen visual interface.
- **jarvis_core.py**: Updated with Agentic Brain for message/email handling.
- **setup.sh**: One-click OS configuration.
